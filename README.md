# Day 6 Talk (MRJ)

Kid-friendly **Day 6 Talk** classroom flow — port of verified APK `MRJ-Day6-Talk-0.3.2`.

1. See the student line (optional Dolly hear)
2. Speak it (Chrome Web Speech · max **5** tries)
3. Hear Mr Jay’s canned reply (Jay teacher mp3)
4. End → **Write this / Results**: success = question + reply; missed = question only (never auto-reveal)

**Brand:** Wait for Languages / MRJ  
**Live:** GitHub Pages from this repo.

Use **Chrome** (desktop or Android) for the mic. Teacher mic on the results page is optional.
